# Aviation Quiz Bot - Advanced Upgrade Requirements

## Project Goal
Upgrade the current Aviation Quiz Bot into a **highly engaging, educational, and competitive** bot specifically for Ethiopian trainee pilot applicants.

The bot must support **two main quiz modes**:  
- **Individual Mode** (existing)  
- **Group Mode** (new major feature)

**Critical Rule**: All questions must remain **open-ended**. Users must type their answers manually. No multiple-choice questions are allowed.

---

## Core Features to Keep
- Open-ended answering with progressive hint system (dashes → random letters → more letters → final reveal)
- Hint timing: First hint after ~12 seconds, then every 20 seconds
- First correct answer wins the point
- Persistent scoring using SQLite
- Aviation-themed, energetic, and professional messaging with relevant emojis (✈️, 🛫, 🏆, 🔥, etc.)

---

## New Major Feature: Group vs Group Mode

### Group Mode Flow
1. User types `/quiz`
2. Bot shows mode selection using **Inline Keyboards**:
   - Individual Competition
   - Group Competition
3. If **Group Competition** is selected:
   - Bot asks how many groups to create (2, 3, or 4)
   - The user who started the quiz becomes the **Group Leader**
   - Leader assigns a **custom name** to each group (e.g., "Sky Hawks", "Bole Eagles", "Addis Future Pilots", "Ethiopian Wings")
   - Users join a group by either typing the group name or clicking inline buttons
   - Group Leader can start the quiz when ready
4. During the quiz:
   - Questions remain fully open-ended
   - The **first correct answer** from any group member gives **1 point to the entire group**
   - Hints work the same as before
5. After each question → Show **Live Group Standings**
6. At the end of the quiz:
   - Final **Group Leaderboard**
   - Individual contributions within each group (how many points each member scored for their team)
